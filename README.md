# Hot Issue Deep Research Archive (`hot-issue-radar`)

핫이슈 딥리서치 아카이브 & 웹 에이전트 정적 사이트 번들입니다.

## 포함 파일
- `index.html`: 핫이슈 아카이브 & 수동 주제 발행 웹 에이전트 앱
- `reports/2026-11-21-black-friday-ai-crash.html`: 2026-11-21 검은 금요일 AI·반도체 폭락 딥리서치 리포트 (v2)
- `deploy.ps1` / `deploy.sh`: GitHub 저장소 생성 + GitHub Pages 자동 발행 스크립트

## 1분 배포 방법 (Windows PowerShell)
1. 이 ZIP 파일의 압축을 푼 폴더에서 PowerShell을 엽니다.
2. `./deploy.ps1` 을 실행합니다. (`gh auth login` 완료 기준)
3. 1~2분 뒤 GitHub Pages 주소에서 모바일·PC 어디서나 열람할 수 있습니다.
